SHORT DESCRIPTION
    PowerShell Web API client for Lua Virtualizer.

LONG DESCRIPTION
    LuaVirtualizer talks to https://www.pelock.com/api/lua-virtualizer/v1
    and exposes the same client surface as the Python SDK.

    Import the module, then either:

        using module LuaVirtualizer
        $client = [LuaVirtualizer]::new('YOUR-KEY')

    or:

        Import-Module LuaVirtualizer
        $client = New-LuaVirtualizer -ApiKey 'YOUR-KEY'

    Empty or invalid keys run demo mode: strategy flags are ignored and the
    service A missing or invalid key is limited to 1000 bytes and the server applies only flat code virtualization (code_virtualization=flat), ignoring every other strategy field.

    Project page: https://www.pelock.com/products/lua-virtualizer
